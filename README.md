# Meme Generator

A simple web app that generates random meme templates and lets you add custom text to the top and bottom.

**Live:** [https://meme-generator-tpxo.onrender.com/](https://meme-generator-tpxo.onrender.com)

## Tech Stack

HTML · CSS · JavaScript

## Run Locally

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd YOUR_REPOSITORY_NAME
```

Open `index.html` in your browser.
